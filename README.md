# Daily Red Lab

[Play the game](https://fmbrandon.github.io/daily-red-lab/) · [Send feedback](https://github.com/fmbrandon/daily-red-lab/issues/new?title=Beta%20feedback)

Unofficial Gen 3 Pokémon battle beta for friends. Battle Daily Red or 32 other opponent profiles, draw random parties from 214 species, and browse the pool in the Pokédex. Battle setup uses bag-style pockets for opponents, parties, and rules.

No installation needed. Progress stays in your browser. Please include the date, opponent, pool, and device when reporting a problem; downloaded battle replays help reproduce it.

See THIRD_PARTY.md and the in-game credits for permissions and asset notices.
